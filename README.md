# 鹈鹕的海边骑行 · 两种风格

这个项目收录了两种可以独立运行的鹈鹕骑行网页。每个版本的 SVG、样式和脚本都包含在各自的 `index.html` 中，无需安装依赖。

| 风格 | 内容 | 本地打开 |
| --- | --- | --- |
| [清新插画版](./鹈鹕骑行本地版/) | 海滨骑行动画、暂停与调速、晴日与日落切换；附 Windows 本地启动器 | 双击 `鹈鹕骑行本地版/index.html`，或在 Windows 解压后运行 `启动网页.bat` |
| [互动探索版](./Pelican-Coast-Offline/) | 海滨骑行动画、场景互动、小发现与旅行明信片；附 Windows、macOS、Linux 启动器 | 双击 `Pelican-Coast-Offline/index.html`，或运行对应系统的启动器 |

项目首页 `index.html` 提供两个版本的入口。本地使用时，直接用浏览器打开它即可；如果将仓库根目录发布为 GitHub Pages，首页和两个版本也可以通过网页链接访问。

完整使用说明分别在 `鹈鹕骑行本地版/使用说明.txt` 和 `Pelican-Coast-Offline/README.txt`。本仓库保留两个原文件夹的目录结构，便于分别使用和修改。
