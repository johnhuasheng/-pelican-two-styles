鹈鹕的海边慢骑 · 本地离线版
Pelican Coast Club

一、最快开始
1. 把 ZIP 完整解压到一个文件夹中。不要只在压缩包预览窗口里运行。
2. Windows：双击 Start-Windows.bat。
   Mac：双击 Start-macOS.command。
   Linux：在解压后的目录里运行 sh Start-Linux.sh。
3. 浏览器会打开动画。关闭网页标签即可退出。

也可以直接用浏览器打开 index.html。这个 HTML 本身就是完整应用。
若 HTML 被文本编辑器打开，请右键“打开方式”，选择浏览器。
若 Mac 启动器没有执行权限，可直接用 Safari 打开 index.html。

二、不需要安装什么
不需要 Python、Node.js、npm 或其他运行环境。
不需要租用服务器、申请公网 IP 或购买域名。
网页、SVG 插画、样式与脚本全部包含在 index.html 中，没有外部资源依赖。
启动器只负责调用系统默认浏览器，不安装软件，也不启动后台服务。
动画在本机浏览器中运行，断网也可以玩。使用支持 JavaScript 的现代浏览器。

三、可以怎么玩
· 暂停／继续、调节速度、按车铃。
· 与鹈鹕打招呼、看跳跃的小鱼、切换日落。
· 换帽子、跳跃、戳气球、寻找螃蟹。
· 看鲸鱼、太阳雨和彩虹，收集 10 个小发现。
· 拍旅行明信片，修改寄语，保存 SVG 或 PNG。
  图片下载位置由浏览器设置决定；若 PNG 无法导出，可保存 SVG。
· 快捷键：空格 暂停／继续；B 车铃；F 小鱼；S 日落；H 换帽；J 跳跃。
· 如果系统启用了“减少动态效果”，页面可能初始暂停，点击播放即可。

四、分享给别人
把整个 ZIP 发给朋友，对方在自己的电脑上解压并启动即可。
这个版本是本地离线应用，不会生成互联网访问链接。
若希望别人无需下载、只点网址即可使用，需要使用网页托管版。

五、修改源码
index.html 就是全部源码。可以用文本编辑器修改，保存后刷新浏览器查看。
启动器与网页必须放在同一个文件夹。
这个离线包不包含网站账号、登录信息或服务端配置。
